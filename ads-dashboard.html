Connect Google Ads

No Google Ads data in the Sheet yet. Spend, clicks and impressions arrive through a Google Ads Script that copies them into the analytics Sheet every hour (full steps in docs/ADS-SETUP.md):

  1. Google Ads → Tools → Bulk actions → Scripts → + New script.
  2. Paste docs/google-ads-script.js, set SHEET_URL to the analytics Sheet, Authorise, then Run.
  3. Set its frequency to Hourly.
  4. Google Ads → Admin → Account settings → Tracking → Final URL suffix: utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_content={adgroupid}&utm_term={keyword}

Sign-ups from ads are already counted below — ad clicks are recognised by Google's click id even before the suffix is set.
