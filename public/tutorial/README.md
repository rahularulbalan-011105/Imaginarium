# Guided-tutorial step videos

Only the steps you **filmed** play a video. Drop those clips here with the **exact
filename** below and the guided coach plays them in that step's dialog. Every
other step stays as **text + a glowing arrow** pointing at the right button.
If a video file is missing, that step shows a 🎬 placeholder until you add it.

Recommended format: **MP4 (H.264)**, muted, short loop, ~640px wide, small file.
